# 版本记录

## v2.50.1 - 2026-09-24

- 修复 Banner 快速创建把后台“保存成功！”提示误判为失败的问题。
- 批量提交完成且至少有一条创建成功后，弹窗底部增加绿色“关闭并刷新页面”按钮。

## v2.50.0 - 2026-09-24

- Banner 列表顶部增加“快速创建”。
- 一次填写活动名称、活动图片、跳转动作、生效时间和失效时间；跳转动作支持按名称或 ID 搜索。
- 展示位置支持多选，提交后按所选位置依次创建多条独立 Banner 记录，并逐条显示创建状态。
- 其余字段沿用后台原生新增表单默认值，同一张活动图片自动复用于本批全部展示位置。

## v2.49.2 - 2026-09-24

- 收藏物品列表行内修改“生效时间”时，改用日期时间选择器，可弹出日历选择日期及时间。
- 选择器使用浏览器标准日期时间格式，保存时自动转换为后台要求的 `YYYY-MM-DD HH:mm:ss`。

## v2.49.1 - 2026-09-24

- 修复收藏物品行内保存返回 HTTP 500 的问题。
- 后台编辑页同时包含多种藏品类型的隐藏字段；保存前现在会合并重复字段，并优先保留当前类型中有值的类别、子类型和物品 ID。
- 行内保存补齐后台原生 AJAX 请求头，并在失败时尽量展示后台返回的具体错误。

## v2.49.0 - 2026-09-24

- 收藏物品列表的“生效时间”和“点亮奖励经验值”支持点击后直接编辑。
- 行内保存会先读取该藏品的原生编辑表单，只替换当前字段后提交，保留类别、礼物、任务配置等其他内容。
- 生效时间支持留空或 `YYYY-MM-DD HH:mm:ss` 格式；经验值限制为非负整数，并显示保存中、成功或失败状态。

## v2.48.1 - 2026-09-23

- 修复批量“快速创建回合地图”勾选“角色独立地图”后状态更新中断、无法提交的问题。
- 移除对内容脚本环境中 `CSS.escape()` 的依赖，直接使用地图 ID 对应的行元素更新角色匹配结果。
- 支持角色地图与普通地图混选：匹配成功的地图选择对应角色，未匹配角色的地图自动选择全部角色，不再锁住整批提交。

## v2.48.0 - 2026-09-23

- 地图列表顶部的批量“快速创建回合地图”弹窗增加“角色独立地图”开关。
- 勾选后逐张地图按名称前缀匹配本剧本角色，并在地图行内显示匹配结果。
- 任一地图未匹配角色时阻止提交；全部匹配后，每条“强制角色进入地图”动作分别选择对应角色，而非全部角色。

## v2.47.1 - 2026-09-23

- 修复单张“快捷创建回合地图”错误从操作列读取地图名称的问题。
- “角色独立地图”现在从名称列读取真实地图名；例如 `风听雨_第一幕` 会按角色名前缀正确匹配“风听雨”。

## v2.47.0 - 2026-09-23

- 地图列表“批量上传地图”支持同时选择静态图片和动态视频。
- 按去除扩展名后的同名文件自动配对，也兼容“名称_静态 + 名称_动态”的命名方式。
- 提交前展示地图名称、静态图片、动态视频和匹配状态；缺少静态图、重名冲突或不支持格式时阻止提交。
- 动态视频为可选项：没有同名视频时仍正常创建静态地图，有同名视频时写入后台原生 `video` 字段。

## v2.46.0 - 2026-09-23

- 技能列表顶部增加“批量创建技能”。
- 支持每行输入一个技能名称，并统一选择物品、角色、地点、互动或道具技能类型。
- 除名称和类型外，其余字段逐条沿用后台原生创建表单默认值；提交过程显示每条状态。

## v2.45.2 - 2026-09-22

- 回合事件创建和编辑页的“触发动作”下方增加“全选动作”“反选”“清空动作”。
- 批量选择后同步刷新后台 Select2，并实时显示已选动作数量。

## v2.45.1 - 2026-09-22

- 回合条件列表最左侧增加“ID”列。
- 从每条条件的查看或编辑链接中提取后台真实条件 ID。

## v2.45.0 - 2026-09-22

- 回合动作列表增加“批量导入地图动作”。
- 支持读取 Excel、CSV 和 TSV 第一张工作表。
- 按“名称、角色、地图、条件”匹配并批量创建“强制角色进入地图”。
- 角色支持多个名称或 ID；地图和条件支持名称或 ID；条件允许留空。
- 提交前逐行预览匹配结果，未匹配、重名和字段缺失会阻止提交。

## v2.44.0 - 2026-09-21

- 地图列表增加多选与批量快速创建回合地图。
