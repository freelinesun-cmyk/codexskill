# 版本记录

## v2.47.0 - 2026-09-23

- 地图列表“批量上传地图”支持同时选择静态图片和动态视频。
- 按去除扩展名后的同名文件自动配对，也兼容“名称_静态 + 名称_动态”的命名方式。
- 提交前展示地图名称、静态图片、动态视频和匹配状态；缺少静态图、重名冲突或不支持格式时阻止提交。
- 动态视频为可选项：没有同名视频时仍正常创建静态地图，有同名视频时写入后台原生 `video` 字段。

## v2.46.0 - 2026-09-23

- 技能列表顶部增加“批量创建技能”。
- 支持每行输入一个技能名称，并统一选择物品、角色、地点、互动或道具技能类型。
- 除名称和类型外，其余字段逐条沿用后台原生创建表单默认值；提交过程显示每条状态。

## v2.45.2 - 2026-09-22

- 回合事件创建和编辑页的“触发动作”下方增加“全选动作”“反选”“清空动作”。
- 批量选择后同步刷新后台 Select2，并实时显示已选动作数量。

## v2.45.1 - 2026-09-22

- 回合条件列表最左侧增加“ID”列。
- 从每条条件的查看或编辑链接中提取后台真实条件 ID。

## v2.45.0 - 2026-09-22

- 回合动作列表增加“批量导入地图动作”。
- 支持读取 Excel、CSV 和 TSV 第一张工作表。
- 按“名称、角色、地图、条件”匹配并批量创建“强制角色进入地图”。
- 角色支持多个名称或 ID；地图和条件支持名称或 ID；条件允许留空。
- 提交前逐行预览匹配结果，未匹配、重名和字段缺失会阻止提交。

## v2.44.0 - 2026-09-21

- 地图列表增加多选与批量快速创建回合地图。
