百变后台辅助工具插件
====================

功能
----
新增：回合列表支持“批量创建回合动作”“批量创建回合事件”“批量添加回合”。先勾选回合，再批量创建进入回合动作：优先按按钮文字匹配同名回合，匹配不到时自动关联列表中的下一回合。按钮文字包含“投票”时，需要在弹窗中为每个投票回合手动选择关联投票组，随后创建“开启投票组”动作。事件功能会关联每个回合的第一条动作；批量添加时每行一个标题，前一回合自动以下一行标题作为按钮文字，最后一行可写“标题 | 自定义按钮文字”。

0. 角色故事批量导入、预览与回合下发：在“角色故事”列表顶部点击“批量导入故事”，选择 baibian.characterStories.v1 JSON。按角色显示名精确匹配，按“标题 + 角色组合”检测重复，默认跳过重复记录，可手动勾选覆盖。任务型故事默认分类为“目的”，普通人物剧情默认分类为“人设”。列表会在“是否有ai总结”后增加“故事”列，点击“点击查看全文”即可弹窗预览单篇后台正文；勾选多篇后点击顶部“查看全文”，可按表格顺序在一个弹窗内合并预览所选正文。插件会移除图片和 Word/WPS 样式，只保留纯文本段落、加粗和文字颜色。勾选若干故事后点击“批量下发回合故事”，动作名称可留空（自动使用回合名称），选择一个回合后即可创建一条“开启角色故事S”动作；剧情包含全部勾选故事，指定角色留空。成功后列表“下发回合”列会记录每个故事已下发到的回合。

1. 条件复制：在回合条件以及“全局配置 → 条件”列表每行“编辑条件”旁增加“复制条件”。点击后插件会优先读取编辑链接中的条件类型编号（cate）来选择相同的条件类型；若链接未提供编号，才按描述匹配。回合条件会填入右侧的创建表单；全局条件会先自动打开后台原有的“添加条件”新建页。插件会在跳转前把原条件配置保存到扩展自身的临时存储，并在新页面加载完成后自动回填文本、单选/多选下拉、复选框、单选框、描述和取反。投票问题选项等依赖父级下拉的数据，会等候选项加载后自动回填。随后清除临时数据。即使后台重定向到规范 URL，也会保留待回填数据；连续复制同一条件类型时无需跳转，也会立即回填。不会修改编辑表单的提交地址，也不会复制原条件 ID。确认无误后点击后台原有的“提交”。

2. 地点列表增强：在“地点管理”列表新增“所属地图”“热区位置”“指示图标位置”三列；内容从该地点的编辑页读取，只展示、不修改后台数据。

3. 新建地点默认热区坐标：在新建地点页面，“热区位置”为空时自动填入 1088、1419、160、100 四行坐标；手动填写的内容不会被覆盖。批量创建地点时也会沿用该默认值。

3. 批量上传地图：在“剧本地图”列表的“添加地图”旁显示“批量上传地图”。选择多张静态图片后，插件会预览清单；每张图片对应一条地图，地图名称取文件名（去掉扩展名），描述留空，动态图不上传。只有点击“确认创建”后才会依次在后台创建地图；完成后刷新列表。

4. 批量上传音乐：在“背景音乐”列表的“添加背景”旁显示“批量上传音乐”。选择多首音频后，插件会预览文件名和自动读取的时长；每首音频创建一条背景音乐，名称保留完整文件名，作者和备注留空。只有点击“确认创建”后才会依次在后台创建音乐；完成后刷新列表。

5. 投票批量配置：在“投票列表”中先勾选投票，再点击“批量添加投票选项”或“批量设置正确答案”。批量添加选项时，每个投票填写一组选项，支持每行一个，也支持输入“A.选项一 B.选项二 C.选项三”，或使用逗号、顿号、分号分隔；文本框下方会实时显示分词预览，插件会按预览结果逐条创建非正确答案选项。批量设置正确答案时，插件会读取所选投票的现有选项，勾选后逐项保存。操作完成后可关闭并刷新列表。

安装
----
1. 解压插件压缩包。
2. 打开 Edge 的 edge://extensions/ 或 Chrome 的 chrome://extensions/。
3. 开启“开发人员模式”。
4. 选择“加载解压缩的扩展”，选中插件文件夹。
5. 刷新百变后台条件页面。

使用
----
点击列表中的“复制条件”，等待“创建”表单填充完成，检查名称和参数后点击后台原有的“提交”。全局条件会自动跳转到“添加条件”页面。
【批量创建地图动作】
在任意回合的“回合动作”列表顶部点击“批量导入地图动作”，选择 Excel、CSV 或 TSV 文件。
读取第一张工作表，表头至少包含“名称、角色、地图”，可选“条件”。角色可填写名称或 ID；多个角色用逗号、顿号或分号分隔；地图和条件可填写名称或 ID；条件允许留空。
插件会先展示逐行匹配预览。存在未匹配、重名或必填字段缺失时不会开放提交；全部校验通过后，按表格顺序创建“强制角色进入地图”动作。
【条件列表显示 ID】
进入回合条件列表后，插件会在列表最左侧增加“ID”列，并从后台查看/编辑链接中读取真实条件 ID。
【回合事件触发动作批量选择】
进入回合事件创建或编辑页后，“触发动作”下方会显示“全选动作”“反选”“清空动作”按钮，并实时显示已选数量。批量选择完成后仍使用后台原有“提交”按钮保存。
【批量创建技能】
进入技能列表后，点击顶部“批量创建技能”。每行输入一个技能名称，统一选择技能类型后确认创建；名称和类型以外的字段均沿用后台原生默认值。
