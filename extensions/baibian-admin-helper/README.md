独立开发目录，对应 `admin.mszmapp.com` 和 `admin-test.mszmapp.com`。

当前包含：Banner 按多选展示位置快速批量创建、收藏物品生效时间和点亮奖励经验值行内编辑、剧本信息轮播图批量上传、角色故事标准 JSON 批量导入（按角色名匹配、正文全文预览、重复检查、可选覆盖，只保留段落/加粗/文字颜色）、角色故事列表单篇及勾选多篇合并查看全文、批量下发回合故事、回合列表批量添加回合/创建回合动作/创建回合事件、回合事件触发动作全选/反选/清空、Excel 批量创建“强制角色进入地图”动作、条件列表显示真实 ID、条件复制、计划任务快捷发放剧本、剧本列表一键创建详情页活动（创建图片模块、上传详情页图片并按名称关联同名线上本）、剧本列表显示角色头像、活动模块批量创建、活动模块批量添加线上本、角色列表按顺序或文件名前缀批量覆盖主图、线索列表无需勾选即可按图片文件名前缀中的线索 ID 自动匹配并批量覆盖主图、调查点列表按多行名称批量创建调查点并可统一关联技能包、调查点列表勾选后按地图批量创建地点（支持统一默认地图，单行地图优先；新建地点默认填入热区坐标 1088/1419/160/100）、调查点列表反查关联地点并显示所属地图、地点列表批量创建、地点列表批量上传指示图/私聊场景图、地点列表地图/热区/指示图标坐标展示、地图列表显示对应地点名称并可将一张地图内景批量覆盖到关联地点的私聊背景图、静态地图与同名动态视频配对批量上传、背景音乐批量上传、地图名称行内编辑、地图与背景音乐快捷创建回合动作、加入回合开始事件并在列表显示已加入的回合历史、回合动作快捷创建事件、按剧本 ID 隔离的地图文件夹配置与地图图片选择、背景音乐列表直接播放/暂停、技能列表按多行名称和统一类型批量创建技能、批量创建投票并逐条设置关联角色、投票列表批量添加投票选项（支持分词预览）和批量设置正确答案、技能列表批量创建调查点等功能。

## Banner 快速创建

进入 Banner 列表后点击顶部“快速创建”，一次填写活动名称、活动图片、跳转动作、生效时间和失效时间，并勾选一个或多个展示位置。插件会沿用后台新增页的其他默认字段，按展示位置逐条创建独立 Banner；例如勾选“首页、主持大厅、剧本推荐”会创建三条记录。弹窗会显示每个位置的创建进度及结果。

## 收藏物品行内编辑

进入“收藏物品”列表后，点击“生效时间”或“点亮奖励经验值”单元格中的文字即可直接修改。生效时间提供日期时间选择器，可弹出日历选择日期及具体时间，也可清空；经验值须为非负整数。保存时插件会读取该藏品的原生编辑表单，只替换正在编辑的字段并提交，其余配置保持不变。

## 批量导入角色故事

在“角色故事”列表顶部点击“批量导入故事”，选择 `baibian.characterStories.v1` JSON 数据包。插件会按显示角色名精确匹配，以“标题 + 角色组合”判断重复；默认跳过已存在记录，勾选“覆盖已存在记录”后才会覆盖。正文在预览和提交前都会清洗：仅保留段落、换行、`<b>` 加粗和 RGB 文字颜色，不导入图片、字体、字号、行距、缩进、斜体、下划线或底色。

任务型故事（标题含“任务”，或正文以“【你的任务】”开头）在记录未明确提供分类时，默认使用“目的”；普通人物剧情默认使用“人设”。

角色故事列表会在“是否有ai总结”后增加“故事”列。点击“点击查看全文”后，插件按需读取该条记录的编辑页，并在当前页面弹窗显示完整正文。

勾选列表左侧的多个故事后，点击顶部“查看全文”，插件会按当前表格顺序读取并拼接所有已选正文，在同一个大弹窗中用“角色 / 标题”分隔展示，便于与合并校对稿逐段核对。若其中一篇读取失败，其余内容仍会继续显示。

列表每行前方带有故事复选框。勾选故事后点击“批量下发回合故事”，可手动填写动作名称并单选一个回合；名称留空时自动使用回合名称。插件会在该回合创建一条“开启角色故事S”动作，将全部勾选故事写入“剧情S”，不配置“指定角色”。提交成功后，“下发回合”列会按剧本分别记录并显示每个故事已经下发到的回合，同一故事可累计多个回合。

## 回合列表批量工具

回合列表新增复选框和三个按钮：“批量创建回合动作”优先按按钮文字匹配同名回合并创建“所有角色进入回合”；如果按钮文字匹配不到，则自动关联当前回合在列表中的下一回合。按钮文字包含“投票”时，弹窗会为每个投票回合增加投票组下拉框，必须手动选择关联投票组后才创建“开启投票组”。“批量创建回合事件”把各回合动作列表的第一条动作加入“所有角色都点击了主按钮”事件；“批量添加回合”按每行一个标题创建，前一回合自动使用下一行标题作为按钮文字，最后一行可写“标题 | 自定义按钮文字”。

地图列表“快捷创建回合地图”弹窗支持勾选“角色独立地图”。勾选后，插件会读取本剧本角色，并用地图名称开头匹配角色名称；地图名后续的幕次、场景、尺寸和版本等后缀会忽略。匹配成功后，“强制角色进入地图”动作只选择该角色；不勾选时仍选择全部角色。

地图列表左侧新增地图复选框，顶部新增“快速创建回合地图”。勾选多张地图后，弹窗会为每张地图分别提供回合下拉框；全部指定后，插件按当前列表顺序逐张创建“强制角色进入地图”动作并加入对应回合的“回合开始”事件，同时保留每张地图的所在回合记录。

批量“快速创建回合地图”同样支持“角色独立地图”。勾选后会逐张地图按名称开头匹配角色，并在每行显示匹配结果；匹配成功的地图选择对应角色，未匹配角色的普通地图自动选择全部角色，因此两类地图可以混合批量处理。

地图列表“批量上传地图”可一次选择静态图片和动态视频。插件按去掉扩展名后的文件名配对，例如 `云祥镇.png` 与 `云祥镇.mp4`；也兼容 `云祥镇_静态.png` 与 `云祥镇_动态.mp4`。静态图片必须存在，动态视频可以省略。提交前会显示配对预览；孤立视频、同名重复文件或不支持格式会阻止提交，避免错配。

动作列表顶部新增“批量导入地图动作”。支持 Excel、CSV 和 TSV，第一张工作表须包含“名称、角色、地图、条件”四列，其中条件允许留空。角色可填写一个或多个名称/ID（多个用逗号、顿号或分号分隔），地图和条件可填写名称或 ID。导入后先逐行预览匹配结果；未匹配、重名或字段缺失的行会阻止提交，全部校验通过后才按表格顺序创建“强制角色进入地图”动作。

加载开发版时，在 Chrome 扩展程序页面选择“加载已解压的扩展程序”，并选择本目录。
