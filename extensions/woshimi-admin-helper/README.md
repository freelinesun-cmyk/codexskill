# 我是谜后台浏览器插件

独立开发目录，对应 `admin.xiyacs.com`。

当前版本：**2.5.10**。完整变化见 [CHANGELOG.md](CHANGELOG.md)，可直接下载
[`releases/我是谜后台辅助工具-v2.5.10.zip`](releases/%E6%88%91%E6%98%AF%E8%B0%9C%E5%90%8E%E5%8F%B0%E8%BE%85%E5%8A%A9%E5%B7%A5%E5%85%B7-v2.5.10.zip)。

当前包含：投票表格序号、投票配置配图/正确答案展示、按投票组分别批量添加选项、投票图片批量上传、线索主图批量上传与单图完整预览、线索调查点批量修改、回合批量创建、自定义快捷创建动作、事件与全局条件、调查点可见条件行内编辑与批量设置等功能。快捷配置保存在扩展本地，点击快捷按钮只打开并预选创建表单，不会自动提交后台。

加载开发版时，在 Chrome 扩展程序页面选择“加载已解压的扩展程序”，并选择本目录。

## 发布约定

每次更新必须同时完成：

1. 更新 `manifest.json` 的版本号；
2. 在 `CHANGELOG.md` 顶部增加版本说明；
3. 将对应 ZIP 放入 `releases/`；
4. 提交源码并创建 `woshimi-admin-helper-v版本号` 格式的 Git 标签。
