# 我是谜后台浏览器插件

独立开发目录，对应 `admin.xiyacs.com`。

当前版本：**2.5.13**。

当前包含：投票表格序号、投票配置配图/正确答案展示、批量添加投票（支持一键关联所有具体角色，并将“多选”和“不定项”统一按多选题创建）、按投票组批量添加选项（支持一次粘贴完整题目与选项并按标题自动分配）、投票图片批量上传（支持选择整个整理文件夹并按投票标题与数字图片名自动匹配）、线索主图批量上传与单图完整预览、线索调查点批量修改、回合批量创建、自定义快捷创建动作、事件与全局条件、调查点可见条件行内编辑与批量设置等功能。快捷配置保存在扩展本地，点击快捷按钮只打开并预选创建表单，不会自动提交后台。

投票图片目录格式见 [投票图片文件夹整理说明.md](投票图片文件夹整理说明.md)。

加载开发版时，在 Chrome 扩展程序页面选择“加载已解压的扩展程序”，并选择本目录。
