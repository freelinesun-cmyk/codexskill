# 移动端排版与校验

只在需要确定画布、字号、内容密度或验收标准时读取本文件。

## 尺寸与字号

推荐母版宽度为 936–1080px。估算手机显示字号：

`手机等效字号 = 母版字号 × 手机显示宽度 ÷ 母版宽度`

例如 936px 宽图片在 375px 宽手机上显示，缩放系数约为 0.40：

| 用途 | 936px 母版建议 | 375px 手机等效 |
| --- | ---: | ---: |
| 最小辅助文字 | 36–40px | 14–16px |
| 正文 | 40–48px | 16–19px |
| 标签、角色属性 | 48–56px | 19–22px |
| 模块标题 | 64–96px | 26–38px |
| 主标题 | 120px 以上 | 48px 以上 |

如果平台会二次缩图或用户明确要求大字，按更窄的实际显示宽度重新计算。

### 默认最低文字标准（硬下限）

以用户确认的参考副标题为基准，宣传图中最小的面向玩家文字不得小于约 **15px 的 375px 手机等效字号**。这包括副标题、标签、角色属性、评论、页脚和行动提示，不存在“装饰性小字”例外。

- 1024px 宽母版：最小字号 **42px**；
- 936px 宽母版：最小字号 **40px**；
- 其他宽度：`最小母版字号 = 15 × 母版宽度 ÷ 375`，结果向上取整。

这是下限，不是推荐字号。若图像生成结果的字面高度无法精确读取，按提示词明确要求该下限，并以 375px 宽预览确认最小文字可不放大阅读。文案放不下时，拆页或删减文案，不能通过缩小任意文字解决。

## 内容密度

- 中文正文每行优先控制在 12–18 个汉字；最多 2–3 行。
- 一个卖点模块只放一个结论和一句解释。
- 同一屏最多使用两栏；手机端两栏只适合短标签或对照关系，不适合长段正文。
- 角色卡只保留姓名、性格定位和一行适配能力。
- 道具区优先使用 3–7 个大图标，不要用大量小图标填满画面。
- 结尾正文保持两段以内，并让行动召唤明显大于解释文字。

## 分页判断

出现任一情况就应拆页：

- 为了容纳文案必须把任意面向玩家文字降到最低文字标准以下；
- 同一屏存在三种以上同等强度的视觉焦点；
- 两栏正文超过三行；
- 角色、道具和卖点必须互相遮挡；
- 手机预览需要放大才能读清。

增加页数后保持每页宽度一致，并在边缘预留 3%–5% 安全区。

## 拼接容错

- 每张分图的顶部和底部预留约 4%–8% 的低信息过渡区。
- 推荐接缝素材：纯色、柔和渐变、纸纹、雾气、无明显轮廓的云层、远山剪影和细颗粒。
- 谨慎使用：松枝、屋檐、山脊、金线、装饰边框等有明确方向或连续轮廓的元素；如果使用，应在接缝前自然结束。
- 禁止让角色身体、脸部、文字、卡片边框、建筑主体、光束和关键道具跨页。
- 两张图只需保持色温、明度和纹理接近，不要设计成必须像素级对齐才能成立的一幅连续插画。
- 拼接后允许存在自然的段落分隔感；不要为了隐藏接缝牺牲分图独立发布时的完整性。
- 不要给每一张分图画完整闭合的外框、纸边或描边：相邻页的底框和顶框会在拼接后形成突兀横线。需要外框时，采用仅左右侧边的开口式边框，并在离顶部/底部 4%–8% 的区域渐隐；接缝自身保持无横线、无闭合边、无高对比装饰。

## 验收方法

1. 记录母版宽度和排版工具中的最小字号，不凭肉眼猜测。
2. 按 375px 或实际投放宽度预览整页，不进行手动放大。
3. 逐字核对标题、人名、地点、玩法名称和行动召唤。
4. 检查 JPEG 压缩后的小字边缘，必要时提高质量或改用 PNG。
5. 同时检查分图和完整拼接图；拼接图过长时，分图仍应能独立发布。
6. 将相邻页面模拟错开 2–4px 检查；如果接缝立刻显得断裂，应改用更柔和、低信息的过渡。
7. 在完整拼接图中逐一放大接缝，检查是否存在两段外框、纸边或描边叠出的水平线；存在时，重生成相邻页面的开口式上下过渡。
