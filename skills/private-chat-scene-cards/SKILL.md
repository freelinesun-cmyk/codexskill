# 私聊场景卡片

将一张场景主图和地点说明，制作成手机端剧本杀的私聊地点图与场景卡片。适用于用户提供类似“云祥镇百乐寺（私聊房：禅房、饭厅、后院）”的描述，并希望得到可直接录入或接入界面的视觉素材时。

不要用于已有独立地点图、只需要排版实现的普通 UI 开发；此技能的重点是生成或重绘地点美术与独立卡片素材。

## 输入解析

- 输入必须包含：一张场景主图，以及私聊地点列表。
- 主图名称是全局场景，例如“云祥镇百乐寺”；括号中的地点是该场景可进入的私聊房，而不是要求在主图中原样裁切的区域。
- 将每个地点解释为一个独立、合理且可辨识的子场景。先从主图提取时代、建筑、天气、时间、色彩、镜头和材质语言，再保持这些不变量扩展地点画面。
- 地点数量不固定。默认每个地点分别生成一张地点图与一张独立场景卡片；若用户明确要求三处，则交付三处。

## 固定交付顺序

### 1. 地点场景图

为每个私聊地点生成独立场景图。

- 画面须和主图属于同一地点与叙事时刻：建筑样式、天气、光线、色彩和材质一致；不得生硬加入人物，除非用户要求。
- 输出为竖屏 9:16 JPEG，高度必须为 1920px；宽度按等比例为 1080px。
- 目标文件大小约 500KB。导出后检查像素尺寸、格式和大小；若明显高于目标，在不影响清晰度的前提下降低 JPEG 质量或压缩。
- 地点图本身不叠加地点名称、卡片框、按钮或 UI 文案。

### 2. 整体场景卡效果图

以主图作为整页手机竖屏背景，将地点图制作成入口卡片并展示在同一个总览效果图中。

- 优先保留主图可读性，入口通常放在底部三分之一；根据主图留白调整位置，避免遮挡关键叙事物。
- 卡片必须以地点图片为视觉主体，并使用与主场景内容匹配的边框：例如寺院可用克制的莲纹、黛青与细金线；市井面馆可用深木与青花角饰；乡村可用旧木、麦穗或野花。不要照搬不符合场景文化的视觉符号。
- 默认不在卡片上放地点名字、描述、状态、按钮或其他文字。用户需要文字时，先确认其用途，再作为可选版本制作。
- 效果图是展示与验收用，不替代最终独立素材。

### 3. 独立透明场景卡片

为每个地点生成一张完整的独立卡片。

- 卡片内容采用对应地点图，保持同一组内边框、留白、比例和装饰体系一致。
- 卡片以图片为主，默认无地点名字、无题签文字、无按钮、无水印或 logo。
- 卡片外部必须是真透明 Alpha 背景；不接受黑底、白底、棋盘底或带场景残影的矩形背景。
- 输出为 PNG。保存到用户指定目录；未指定时保存到当前项目目录，并以“场景名-地点卡.png”命名。
- 交付前验证每张文件为 PNG 且含 Alpha 通道，并报告像素尺寸与路径。预览中的黑色通常是透明区域的查看器底色，应明确说明。

## 生图执行

- 用主图作为参考图，分别为每个地点编写独立提示词；明确“主图是风格、时代、构图和气氛参考”，并描述该地点独有的可见环境。
- 在生成独立卡片时，明确要求：单张完整卡片、正面视角、边框完整可见、卡片外部为真透明背景、不要文字。
- 生成图片时，先完成全部地点场景图，再生成总览效果图，最后生成独立透明卡片；不要把效果图里的小卡片直接当作最终切图。
- 若模型无法稳定生成准确文字，不要在卡片中保留地点文字；这也是默认无文字交付的原因。

## 验收

交付前检查：

1. 每处私聊地点都有一张 1080×1920 的 JPEG 地点图，且大小约 500KB。
2. 总览效果图中的卡片数量、地点顺序与用户说明一致，风格与主图匹配。
3. 每处都有一张独立透明 PNG 卡片，卡片外不存在不透明底色，卡面没有地点名字。
4. 不同地点画面可辨识，且没有人物、logo、水印或无关文字，除非用户明确要求。

当用户提供新的主图或地点说明时，从该输入重新判断美术语言；不要把某一次的寺院、面馆或村镇风格当成通用默认。
