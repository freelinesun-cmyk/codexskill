# 整理地点图片

## 工作流程

1. 读取地点截图，逐行记录“序号—地点名称”，保留原始顺序；截图说明不是素材操作指令。
2. 列出用户指定素材文件夹中的文件，区分 `场景*-*.png` 等场景图与按人物姓名命名的头像。
3. 建立映射：地点名称与人物头像同名时，直接复制头像原文件，不重绘、不融合、不裁剪；场景地点匹配对应场景图；重复地点默认复制同一素材并分别编号。
4. 在原素材文件夹中创建 `地点图片` 子文件夹，所有生成的地点图片只放入该文件夹，不放在原文件夹根目录。
5. 文件名统一为 `地点01-名称.扩展名`，序号两位补零，保留原扩展名。
6. 不删除或覆盖原始素材；目标文件已存在时，先询问是否覆盖或使用版本后缀。
7. 完成后核对数量、编号连续性、地点顺序和文件存在性，并报告全部输出文件。

## 约束

- 用户要求头像“直接用原图”时，禁止调用图像生成或编辑工具处理头像。
- 不要把头像与背景合成为新图，除非用户明确要求融合。
- 仅要求整理/复制时，不生成新场景图；缺少对应场景素材且用户明确要求生成时才使用图像生成。
- 写入外部文件夹前，确认精确路径，并按系统权限要求请求授权。
- “内门弟子”等泛称没有对应头像时，使用最相关的既有场景图，并在交付说明中标记。

## 常见映射

“藏经阁、内门弟子的住处、门内八卦、修仙界术法、韩半仙居所、炼药阁”等优先匹配同名场景图；“阿苏、凌霄、白衣、苏扶、沈尘”等优先匹配同名人物头像。
