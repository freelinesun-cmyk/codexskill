# 按钮循环放大

用于为已有透明 PNG 制作循环缩放动画。这是确定性的图像处理流程，不使用图像生成。

## 必填输入

获取图片与其**最大放大倍率**。这是唯一需要用户指定的动画参数；必须大于 `1`，例如 `1.1`、`1.2` 或 `1.3`。除非用户明确要求，否则保持下列默认配置。

## 默认输出

- 保留原始 PNG 及其透明通道。
- 在原图旁输出 `<原文件名>_缩放循环_<倍率>x.gif` 和 `<原文件名>_缩放循环_<倍率>x.webp`。
- 制作两秒、无限循环的往返缩放动画：从 `1.0` 放大到指定最大倍率，再回到 `1.0`。
- 画布宽高均为 `ceil(原图尺寸 × 最大倍率) + 8 px`。先将原图居中置入画布，四像素安全边距可避免最大放大帧裁边。
- 先生成 GIF，再生成动画 WebP。每个文件以 3 MiB 以内为目标；仅在必要时降低 GIF 帧数、调色板颜色数或 WebP 质量。
- 不得仅为压缩体积而缩小原图或裁切画面。若不能在不采取这些措施的情况下达到目标体积，应如实告知用户。

## 执行

执行内置脚本。默认输出到原图所在目录；仅在用户指定其他位置时使用 `--output-dir`。除非用户已授权替换，使用 `--overwrite` 前不得覆盖同名输出。

```bash
python3 scripts/make_zoom_animation.py "/absolute/path/to/asset.png" --scale 1.2
```

## 验证

导出后检查两个文件的尺寸和体积。查看最大放大倍率时的中间帧，尤其确认贴近边缘的描边、发光、文字和装饰没有被裁切。报告路径前，确认 GIF 与 WebP 均无限循环并保留透明通道。
