# 剧本结构化物料

## 回合流程

识别剧本中的剧情、搜证、圆桌和投票回合，保持文档出现顺序。输出：

- 带类型和幕次的完整回合清单。
- 仅包含标题的单列列表，用于批量建立回合或书牌。

不要仅按“第一幕、第二幕”粗略归并；剧情、搜证、圆桌和投票是独立回合时应分别保留。

## 投票

在每幕投票或圆桌问题区域提取：幕次、投票标题、投票选项。投票答案仅在用户明确要求时输出，不混入线索表。

同时提供只包含投票标题的单列列表，顺序与剧本一致。区分单选、多选和角色专属问题；无法从文档确定时标注待确认，不猜测。

## 调查点统计

以每幕实际线索条数为基数。若角色人数为 `N`，每名角色该幕调查点为：

`向上取整（该幕线索数 ÷ N）`

逐幕计算后相加，不用全剧线索总数一次性除法替代。报告每幕线索数、每人调查点和全剧每人合计；同时说明因向上取整产生的冗余调查点。

## 检查

- 回合和投票顺序与源文档一致。
- 投票问题、选项边界准确。
- 每幕线索数与线索表实际行数一致。
- 调查点计算逐幕向上取整且总计正确。
