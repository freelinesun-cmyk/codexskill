# 调查点场景图片

为线索表中的每一个调查点制作一张场景图片。图片用于表现玩家搜证时看到的地点环境，而不是把所有线索画成信息图。

## 画面内容

- The main subject should have refined and precise details. Keep the background clean, simple, low-noise, and secondary. 画面不要太昏暗。
- **清透卡通版默认风格（重点）**：除非用户明确指定其他画风，每条地点场景提示词都必须原样加入：“清透卡通版：减少繁杂纹理与涂抹感，改成平滑赛璐璐色块、柔和冷暖光和更干净的环境层次。” 优先使用平滑赛璐璐色块、清晰环境分层与克制纹理，避免厚重涂抹、碎纹理堆叠、过度写实噪点或烟雾遮挡；环境仍须完整、自然连续。
- 综合剧本剧情、时代背景、整体美术风格和该调查点的线索，概括场景的地点、环境、陈设和氛围。
- 以地点场景为主。若一个府邸含有多条线索，表现府邸的外貌或代表性环境即可，无需逐条呈现线索。
- 人物调查点可表现其常驻空间、相关房间或具有代表性的环境；只有在地点无法表达时才以人物为视觉主体。
- 不加入文字、标题、编号、界面、水印或可读招牌。
- 不为了涵盖每条线索而堆砌物件；优先保证画面自然、统一且能辨认地点。

## 默认规格

- 每个调查点一张图。
- 比例：`1:1`。
- 可先生成约 1K 分辨率的原图。
- 最终尺寸：`800 × 800` 像素。
- 最终格式：JPEG。
- 每张文件大小目标约 `150 KB`；在画质可接受的前提下压缩，允许小幅浮动。
- 统一使用 RGB 色彩模式。

## 文件组织

- 按调查点出现顺序输出。
- 文件名应包含调查点顺序或 ID 和纯线索包名称，避免同名覆盖。
- 另存到独立的“调查点场景图片”目录，不覆盖已有素材。

## 生成与校验

1. 先为每个调查点写一条简洁的场景提示词，明确地点、时代、时间、光线、主要建筑或陈设和氛围。
2. 检查提示词未误把投票、答案或复盘内容当作画面依据。
3. 生成后检查无文字、无明显现代物件、无重复或错配场景。
4. 转换为 JPEG、缩放至 800×800，并逐张检查像素尺寸、色彩模式和文件大小。
5. 报告应生成数量、失败数量及超过目标体积仍无法无损观感压缩的图片。
